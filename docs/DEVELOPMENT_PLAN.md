# Step-by-Step Development Plan

1. Initialize monorepo with `client` and `server` workspaces.
2. Configure Express, environment variables, security middleware, and central error handling.
3. Create PostgreSQL schema with roles, users, stores, and ratings.
4. Implement auth with signup, login, JWT, bcrypt, protected routes, and change password.
5. Build admin APIs for users, stores, ratings, and analytics.
6. Build normal user APIs for browsing stores and submitting/updating ratings.
7. Build store owner APIs for average rating and rated-user analytics.
8. Scaffold React app with Tailwind, routing, Axios, auth context, and toasts.
9. Build shared UI components and responsive dashboard layout.
10. Implement admin, user, and owner pages.
11. Add validation on both client and server.
12. Verify migrations, seed data, API flows, and frontend build.
13. Prepare deployment configuration and production environment variables.

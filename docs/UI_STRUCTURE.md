# Professional UI Design Structure

## Layout

- Fixed desktop sidebar for role navigation
- Sticky top bar with account identity and logout
- Mobile horizontal navigation below the header
- Constrained content width for readable dashboard surfaces

## Admin Experience

- Analytics cards for total users, stores, ratings, and platform average
- Management tables with search and filters
- Inline create forms for users/admins/owners and stores
- Action buttons use icons for repeated operations

## Normal User Experience

- Responsive store cards for scanning on desktop and mobile
- Search by store name or address
- Star selector for rating creation and modification
- Current average and total ratings visible on each card

## Store Owner Experience

- Summary cards for average rating and total ratings
- Store selector for owners with multiple stores
- Table of users who rated the selected store

## Visual System

- Neutral background for operational clarity
- White panels and compact 8px-radius cards
- Green primary actions
- Amber star ratings
- Slate text palette for strong readability
